# AIの実行記録（任意）

`recorded_gemini_run.json` は、非公開のエージェントサービス（Gemini が方策）を1回だけ実行した記録です。公開画面は Gemini を呼び出さず、このファイルがあれば次を確認してから表示します。

1. 契約（`RecordedAgentRun`）に合うこと。
2. 記録された判断を同じ合成シナリオで**再生**すると、観測・道具の結果・入力ダイジェスト・結論がすべて一致すること。

一致しなければ表示しません（画面には「再生検証に一致しない」と出ます）。

## 作成方法（課金あり・明示的な承認が必要）

```bash
python scripts/record_gemini_run.py \
  --service-url https://<非公開サービスのURL> \
  --confirm-paid-call
```

Gemini を最大6回呼び出します。スクリプトは保存前に手元でも再生検証し、一致しない記録は保存しません。

## 限界

再生検証が保証するのは「記録された判断から、記録された結果が導かれること」です。判断そのものが Gemini の出力であることは署名していないため保証しません。テスト用の台本や手書きの判断をこのファイルに置いて、Gemini の記録として見せないでください。
