# 合成データ

ここにあるのは、説明のために作った架空の道路・住民・避難所だけです。公的なハザードデータでも現実の地図でもなく、個人情報も含みません。閉鎖期間・移動時間・定員などは任意のテスト値で、現実の防災基準として使わないでください。

## `demo_area/blocked_route`（基本：住民2名・道路3本）

- `scenario.json`：世界の条件
- `plan.json`：閉鎖中の道路を通る計画（FAILになる）
- `repaired_plan.json`：人が作った迂回の計画（AIが作ったものではない）
- `expected.json`：テストで使う期待値

## `demo_area/river_district`（川沿いの地区：住民12名）

住民12名（北・川沿い・東の各4名）、避難所3か所（小学校5名・公民館4名・高台公園8名。高台は240秒に開設）、道路10本の架空の地区です。川沿いの道（`flooded_lane`）は全時間浸水、橋（`river_bridge`）は300秒で通行止めになります。

- `scenario.json`：世界の条件
- `plan.json`：「全員が最寄りの小学校へ、閉鎖も定員も考えずに向かう」素朴な計画（浸水と定員超過でFAIL）
- `care.json`：12人の事情メモ、避難所3か所の設備の説明、職員が設定した「避ける避難所と理由」
- `residents.json`：架空の住民100人のプール。名前・年齢・本人の言葉のメモと、職員の設定だけを持ち、出身・国籍・宗教の項目はない。最初の12人は `care.json` と同じ

エージェントは素朴な計画を修復し、使う道路8本を1本ずつ閉じて試します。事情の条件がなければ4本には代替計画を用意でき、残る4本（北地区の唯一の出口 `north_exit`、橋 `river_bridge` とそこへ続く道 `river_path`、高台への坂道 `hill_road`）はこの道路網に代わりがありません。`care.json` の職員の設定（12人の事情）を守る条件では、8本とも代替計画が見つかりません。どちらの場合も、人へ引き継ぎます。

## `evidence/`

非公開サービスでGeminiを動かした実行の記録です。公開画面は、記録した判断を再生して結果が一致したときだけ表示します（[説明](evidence/README.md)）。
