# Geminiへの指示文（プロンプト）

指示文はコードの中の長い文字列ではなく、版つきのファイルとして置いています。読み込みは `loader.py` が行い、Geminiの答えには使った版を記録します（例：`AgentTrace.prompt_version`）。

| ファイル | 使う場面 |
|---|---|
| `care_reader/v2_system.txt` | 住民の事情メモと避難所の設備を読み、「誰が・どの避難所を・どの理由で避けるか」を返す。名前・年齢・国籍・宗教・言語などだけから事情を推し量らないよう指示している（v1は旧版。以前の版で読んだ答えも受け取れるように残している） |
| `report_reader/v1_system.txt` | 1行の報告文から、通れない道路を最大2本選ぶ。報告文はデータとして扱い、その中の指示には従わない |
| `orchestrator/v2_system.txt` | エージェントの方策。毎ステップ、許された行動から1つを選ぶ。PASS/FAILは変えられない |
| `resident/v1_system.txt` | 住民役の行動意図を作る（Gemmaの今後の工程用。本番では使っていない） |

どの場面でも、答えの形は列挙型に絞った構造化出力で受け取り、受け取った側でも厳格な型で確かめます。
