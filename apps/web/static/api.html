公開API / EVACWEAVE

公開APIの一覧

応答は、同梱の合成データを決定論的Simulation Coreで計算した結果です。公開サービス自身はGeminiやGemmaを呼び出しません。POST /v1/agent/read と POST /v1/agent/live だけは、IAMで保護した非公開サービスにGeminiでの処理を依頼し、返ってきた答えをここで確かめてから返します。

合成データのみ

エンドポイント

認証不要・読み取り中心
メソッドパス内容
GET/health稼働確認。status、サービス名、デプロイ版(revision)を返します。
GET/v1/showcase公開画面が表示する証拠一式。ルール方策で実行したエージェントの全ステップ（修復・弱点探索・代替計画）を基本シナリオと川沿いの地区（more_runs）について含み、再生検証に通った場合のみGeminiの実行記録も含みます。live_ai_usedは常にfalseです。
POST/v1/agent/challenge固定の合成シナリオの道路を1〜2本、全時間通行止めにして（{"scenario":"base","closed_roads":["road_b1"]}）、ルール方策のエージェントに立て直させます。閉鎖した世界と、Simulation Coreで検証した全ステップを返します。組合せは有限なので結果をキャッシュします。課金なし。
POST/v1/agent/read状況報告の読み取り（{"scenario":"river_district","report":"橋が冠水して渡れない"}、120文字以内の1行）。非公開サービスでVertex AIのGeminiが報告を読み、通れない道路をその街の道路の中から最大2本選びます（回答の型は道路IDの列挙だけ）。公開サービスでも道路IDを確かめてから返します。読み取りだけで計画は変わりません。課金を伴うため既定で無効（503）。1回の読み取りは1日の回数に1回と数えます。
GET/v1/agent/care住民の事情メモと避難所の設備（?scenario=river_district&pattern=0）。架空の住民12人の短いメモと、3か所の避難所の設備の説明、職員が同じメモから設定した場合の条件（比較用）を返します。pattern（0〜29）を変えると、架空の住民100人から選んだ別の12人が同じ家に住みます（0は元の12人）。住民の項目は名前・年齢・本人の言葉のメモだけで、出身・国籍・宗教などの項目はありません。
GET/v1/agent/care/sweep100人で一括検算（?scenario=river_district）。30通りの組み合わせそれぞれを、職員の設定と平常時の道路でSimulation Coreが検算し、全員の避難先が決まるか、決まらない理由（事情に合う避難所がない人・定員不足・経路不足）を返します。さらに、避難所1か所に設備を1つ足す（その理由の条件を外す）か定員を2人増やした場合に救える組み合わせと、順に足したときの効果を返します。AIは使いません（決定論で計算し、結果は保持して使い回します）。
POST/v1/agent/care事情メモの読み取り（{"scenario":"river_district","pattern":0,"notes":[{"actor_id":"north_01","note":"車椅子を使っている"}]}、書き換えたメモだけ送る。1件100文字以内の1行）。非公開サービスでVertex AIのGeminiがメモと設備を読み、住民ごとに避けるべき避難所と理由を返します（回答の型は住民ID・避難所ID・決められた理由の列挙だけ）。公開サービスでもIDを確かめてから返します。返った条件を restrictions として /v1/agent/live・/v1/agent/challenge に渡すと、計画はその条件を守って作られ、Simulation Coreが守れているかを判定します。課金を伴うため既定で無効（503）。1回の読み取りは1日の回数に1回と数えます。
GET/v1/agent/liveGeminiのライブ実行の状態。有効か、実行中か、1日の上限と本日の残り回数を返します。
POST/v1/agent/live固定の合成シナリオ（{"scenario":"base"} または "river_district"。closed_roads で道路を1〜2本閉鎖した世界も可）で、Vertex AIのGeminiを方策とするエージェントを1回実行します。公開サービスはIAM認証で非公開サービスを呼び出し、返ってきた判断をSimulation Coreで再生して、結果が完全に一致した場合だけ返します。課金を伴うため既定で無効（503）。同時実行は1件（429）、1日の回数上限あり（429）。
GET/v1/demo/blocked道路閉鎖を通る基準計画の検証結果(FAIL)。
GET/v1/demo/repaired開通している道路だけを使う修正計画の検証結果(PASS)。
POST/v1/simulate任意の合成シナリオと計画の検証。厳格なJSON、64 KiB、計算量の上限つき。公開サービスでは既定で無効で、403を返します。
GET/openapi.json機械可読なOpenAPI定義。

呼び出し例

curl
curl -s <公開URL>/health
curl -s <公開URL>/v1/demo/blocked
curl -s <公開URL>/v1/showcase

PASS/FAILは合成シナリオ上の成立性だけを表し、現実の安全や避難判断を保証しません。

EvacWeave — 検証可能な避難AIエージェント合成シナリオによる研究用試作／現実の安全や避難判断を保証しません。
