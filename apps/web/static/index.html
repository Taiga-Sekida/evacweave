その避難計画は、本当に間に合うか。

道路の通行止め・移動時間・避難所の定員・期限を、決定論的なSimulation Coreが検算します。PASS/FAILを決めるのはAIの文章ではなく、計算です。

      ✓
      重要な境界

      生成AIは世界状態や判定を直接書き換えられません。不成立の計画を「完了」にする判断は拒否されます。現実の安全性を保証するものではありません。

      Geminiは非公開サービスで、報告文の読み取りとエージェントの方策を担います。トップのプレイ画面の「Geminiで計画を立て直す」と、場面9の「Geminiでライブ実行」で非公開サービスのGeminiが判断し、この場面の既定の表示と「AIなしで比較」はルール方策です。Geminiの結果は、ライブ・記録とも、Coreで再生して一致した場合だけ表示します。住民役などのGemma専門AIは学習・評価後に接続します。

      07 / Google Cloudとアクセス制御

      見せる処理と、守る処理を分離する。

      公開画面からAI用の認証情報を扱わせない設計です。

      Vertex AIを呼ぶ唯一のサービス

      公開サービスはVertex AIの権限を持ちません。ライブ実行では、固定の合成シナリオに限り、専用サービスアカウントのIDトークンで非公開サービスを呼び出し、返ってきた判断をSimulation Coreで再生して一致した場合だけ表示します。モデルに届く訪問者の入力は報告文1行だけで、データとして渡し、Geminiが返せるのはその街の道路IDだけです。読み取った道路は画面に表示し、その世界の計画も必ずCoreが検証します。
